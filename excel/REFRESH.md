# Dashboard Data and Refresh Guide

The management dashboard was built in Google Sheets using results from PostgreSQL and exported as `Delivery_Risk_Management_Report.xlsx`.

The workbook contains six data sheets and a dashboard with four charts. All displayed results come from the Olist dataset and were validated using SQL reconciliation checks.

## Data sources

The dashboard uses six CSV files generated by `sql/07_export.sql`.

| CSV file         | Spreadsheet sheet | Purpose                                 |
| ---------------- | ----------------- | --------------------------------------- |
| `kpis.csv`       | `Data_KPIs`       | Overall delivery performance            |
| `monthly.csv`    | `Data_Monthly`    | Monthly order value and delivery delays |
| `states.csv`     | `Data_States`     | Geographic delivery performance         |
| `categories.csv` | `Data_Categories` | Product category comparisons            |
| `sellers.csv`    | `Data_Sellers`    | Seller-level performance                |
| `reviews.csv`    | `Data_Reviews`    | Customer satisfaction                   |

All six exported CSV files are available in the `exports/` directory.

## Refreshing the dashboard

The included workbook is already populated with verified results. Refreshing is only necessary when rerunning the analysis or changing the underlying data.

1. Run the PostgreSQL analysis and reconciliation scripts.
2. Execute `sql/07_export.sql` to regenerate the six CSV files.
3. Open the workbook in Google Sheets.
4. Select the corresponding `Data_` sheet.
5. Choose **File → Import → Upload** and select the CSV.
6. Set **Import location → Replace data at selected cell**, starting at `A1`.
7. Repeat for the remaining files and verify that the dashboard charts update correctly.
8. Download the completed workbook using **File → Download → Microsoft Excel (.xlsx)**.

CSV values use decimal points. Check that Google Sheets recognises numerical columns as numbers and does not incorrectly apply percentage formatting.

## Dashboard design

The dashboard presents four views:

- Monthly late delivery rate.
- Monthly merchandise value.
- Categories ranked by merchandise value associated with late deliveries.
- States ranked by merchandise value associated with late deliveries.

The charts use PostgreSQL-generated summary tables rather than recalculating business metrics inside the spreadsheet.

This keeps metric definitions consistent between the SQL analysis and the management report.

The workbook contains formatted data sheets and linked charts, not native Excel PivotTables. The exported tables can also be used to create PivotTables or pivot tables in Google Sheets.

## Validation

Before publishing updated results:

- Confirm all seven SQL reconciliation checks pass.
- Verify that the imported values are numeric.
- Check that chart ranges cover the intended records.
- Ensure dashboard totals match the SQL output.
- Do not describe merchandise value associated with delayed deliveries as lost revenue.
